# 🍿 Mini Movie Matchmaker

Welcome to my Python data filtering project! 

## 🎮 What is this?
This is a simple Python program that acts like a mini recommendation engine. You tell it what kind of movie you want to watch (like "Action" or "Animation"), and it sorts through a list of data to find the perfect matches for you. 

It's a tiny version of how big streaming apps organize and recommend shows!

## 🛠️ How the Magic Works
I built this using **Python Lists**. Think of a list like a giant toy box where we keep our information. 
* **The Database:** I created a big list that holds smaller lists (each small list has a movie title and its genre).
* **The Sorter:** I used a `for` loop to look at every single movie in the box, one by one.
* **The Collector:** If a movie matches what the user typed, an empty list uses the `.append()` command to grab the movie and collect it for the final result.

## 🚀 How to run it
1. Make sure you have Python installed on your computer.
2. Download the `movie_matchmaker.py` file.
3. Open your terminal or command prompt.
4. Run this command:
   `python movie_matchmaker.py`
5. Type in your favorite genre and press Enter!
